Customer Ticket Tracking

Customer-facing status for support requests (missing order, refund, etc.), not shipment tracking. Focus: let customers see progress without sending follow-up messages.

1. Benchmarks

How common platforms expose ticket status to customers today. Screens below are simplified representations of each pattern.

Product Customer sees How they get updates Gap for this use case
Zendesk Help Center Logged-in portal: list of requests, status, comments Email + portal Statuses often generic unless customized

2. Proposed design

Customer-facing request tracking with a request ID, visible stages, and notifications on each change. Same request is reused when the customer adds more info.
