Customer Ticket Tracking

Proposed status-tracking flows built on noon’s current entry points (Orders support, Refunds support, Returns support). Focus: after a customer picks an issue, they get a request they can check instead of sending follow-up messages.

A. Never received shipment B. Damaged / wrong item C. Refund tracking D. Request a refund E. Track return pickup
Improvement over today’s opening screens: keep the same issue menus, then attach a request ID + live status page (and push/email on each stage). “Refund tracking” and “I never received my shipment” become the highest-impact places to start.
